# 五笔打字提示器 · 手机版（APK）

安卓手机直接装 **`wubi-dazi-tishiqi.apk`** 就能用，**默认完全离线**：不填密钥就不联网，中文标五笔、练习模式全程本地。

想让它翻译英文更顺，可以在侧边栏「翻译设置」里填一个免费的百度翻译密钥，**联网只在你打开开关时才发生**。

- 电脑版在 `..\pc\`（双击 `index.html` 用浏览器打开）
- 手机版源码 / 打包脚本都在本目录

---

## 一、安装

把 `wubi-dazi-tishiqi.apk` 传到手机上（数据线、微信文件传输、U 盘都行），点开安装。

第一次装会提示「未知来源」——允许一下即可，这是安卓对所有非应用商店 APK 的标准提醒。

| 项 | 值 |
| --- | --- |
| 应用名 | 五笔提示器 |
| 包名 | `com.wubi.hint` |
| 版本 | 1.4（versionCode 5） |
| 支持系统 | Android 5.0 及以上（minSdk 21），targetSdk 34 |
| 体积 | 约 1.63 MB |
| 权限 | 只有**网络访问**一条，且只在你打开「联网翻译」时用 |

卸载：长按图标 → 卸载，和普通 App 一样。

## 二、怎么用

### 日常模式（打开就是）

上半是输入框，下半是输出框：

- **汉字** → 原样输出，**每个字上方标出它的五笔 86 全码**（如「我」上方是 `TRNT`），字与字之间留了间距方便对照
- **英文** → 自动查词典翻成中文，译文同样标五笔
- **其他语言 / 不明字符** → 原样输出，下方红条提示「无法理解」
- **混在一起** → 各按各的规则处理，互不影响

底部下拉框三种输出方式：`自动检测`（默认）/ `仅标注五笔` / `中文译英（实验）`。

### 练习模式（点蓝色的 `◎ 练习 learn`）

- **上半**：由常用 1000 字组成的十篇文章，可下拉换篇
- **下半**：输入框，照着上面的文章打
- 打完一个字，文章里对应的字**上方就出现它的五笔字母**，打对的字变绿
- 标点、空格不用打，自动跳过
- 进度条显示 `已打 / 总字数`，打错会标红并计数
- 再点蓝色按钮（这时写着 `↩ 日常 返回`）回到日常模式，按钮文字跟着变

练习界面的两个按钮：

| 按钮 | 作用 |
| --- | --- |
| `答案对照模式 开/关` | 开着时**全篇每个字上方都显示五笔**，可以先看答案；打错的字标红 |
| `逐字五笔提示 开/关` | 开着时打一个字才出这个字的五笔（默认开） |

### 侧边栏 & 夜间模式

左上角的 **☰** 按钮拉开左侧抽屉：

- 抽屉里有一个 **🌙 夜间模式** 开关行，点一下整页切成深色（夜间模式），**再点一下回到正常模式**
- 切换时图标会在月亮 / 太阳之间互换，右侧开关滑块跟着滑动，行文字在「夜间模式」/「正常模式」之间变化
- 状态栏、导航栏颜色也会跟着变（由原生侧同步设置）
- 选择会**记住**：下次打开 App 还是上次的模式
- 关抽屉的方式有三种：再点 ☰、点抽屉右侧的灰色遮罩、在抽屉里向右滑一下

### 联网翻译（可选，默认关闭）

侧边栏里还有两行：

| 行 | 作用 |
| --- | --- |
| `🌐 联网翻译 [开关]` | 打开后，英文**整句**发给百度翻译，译文再标五笔 |
| `⚙ 翻译设置` | 填百度翻译的 APP ID 和密钥，带「测试」按钮 |

**怎么申请（免费，约 3 分钟）**

1. 手机或电脑打开 `fanyi-api.baidu.com`，用百度账号登录
2. 点「立即使用」→ 选「个人开发者」→ 应用名随便填（如 `wubi-dazi-tishiqi.apk`）
3. 接入方式选 **API**，提交后立刻开通，页面给出 **APP ID** 和 **密钥**
4. 想额度更高（每月 100 万字符）可在控制台完成个人认证升级高级版

**关于额度和密钥**

- 密钥**不会过期**，绑定你的百度账号，只在这台手机上保存
- 密钥输入框显示为**圆点**，右侧 👁 按钮可以按一下临时显示明文、再按一下盖回去
- 密钥**不进系统备份**（`allowBackup=false`），换机、云备份、数据迁移都不会把它带出去
- 免费额度**按月重置**：标准版 5 万字符 / 月，实名升级高级版 100 万字符 / 月
- 一个账号只有一组密钥；别把密钥公开贴到网上（会被别人用光额度）；如果怀疑泄露，百度控制台可以「重置密钥」
- 标准版 **QPS = 1**（每秒只能请求 1 次），所以程序把请求排成队列、每次间隔 1.3 秒；如果你看到「访问太频繁（54003）」等一秒就好

**每月用量与上限（1.4 新增）**

- 设置面板里有「每月上限（字符，0 = 不限）」，默认 **40000**
- 底部一行实时显示「本月联网已用 X / Y 字符（年-月）」，侧边栏提示条也会同步显示「本月已用 N 字符」
- 用到 **80%** 时数字变黄提醒，到 **100%** 时变红并**自动关闭联网翻译**，输出区显示「本月联网字符数已到 N 上限，已自动关闭联网（下月自动重置）」
- 统计只计**真正发出去的字符**：命中本地缓存的句子不计数（百度也不收费），所以实际消耗不会比显示的多
- 每个月 1 号自动清零；想继续用就把上限调大或填 0

**它是怎么工作的（三层回退）**

1. 本地修正表先跑（508 条，0 延迟）
2. 剩下的英文整段发百度，回来的译文直接替换
3. 没网 / 超时 / 额度用完 / 密钥错 → **自动退回离线逐词翻译**，并在输出区下方显示红条说明原因（如「APP ID 或密钥不正确（52003），已用离线词典。」），功能不会不可用

其他细节：

- 同一句话有缓存，改一个字才重新请求；请求串行发送，遵守百度 QPS 限制
- 中文标五笔、练习模式**永远在本地**，不发任何数据
- 关掉开关就完全离线，和 1.2 版一样

### 返回键

- 翻译设置面板开着时按返回 → 先关面板
- 侧边栏开着时按返回 → 先关掉侧边栏（不退出 App）
- 练习模式里按返回 → 退回日常模式（不会退出 App）
- 日常模式里按返回 → 退出 App

### 输入法

手机打中文走输入法：先打拼音字母、再选字。程序**已经处理了拼字中间态**——打拼音时的字母不会被判成错字，选字提交后才比对。已用真机输入法流程验证通过。

## 四、改内容 & 重新打包

### 只改资源包（最常见）

资源包都是**普通 JS 文件**，用记事本就能改，格式说明见 `www\README.md` 第三节。

改完 → 双击运行 `build.py`（或命令行 `python build.py`）→ 生成新的 `wubi-dazi-tishiqi.apk`。

### 打包环境

`build.py` 里写死了这两个路径，换机器要改开头几行：

```python
JDK = r"E:\edownload\Kimi\runtime"                      # 需要 java/javac/jar/keytool
SDK = r"D:\deepseeklearn\android\sdk"                   # 需要 build-tools 34.0.0 + platforms\android-34
```

不用 Gradle、不用 Android Studio，脚本自己调 aapt2 / javac / d8 / zipalign / apksigner，全程离线。

### 打包流程（`build.py` 七步）

1. `aapt2 compile` 把 `res\` 编成 `.flat`
2. `aapt2 link` 出基础 APK，同时把 `www\` 铺进 `assets\www\`
3. `javac` 编译 Java 源码
4. `d8` 把 class 转成 `classes.dex`
5. 把 `classes.dex` 塞进 APK
6. `zipalign` 对齐
7. `apksigner` 签名并校验

### 换签名证书

删掉 `wubi-release.keystore`，`build.py` 会自动用 keytool 重新生成一个（口令写在脚本里）。

> 注意：换证书后新旧 APK 无法覆盖安装，要先卸载旧的。

## 六、技术说明与已知限制

- 界面是**纯 WebView 加载本地网页**（`file:///android_asset/www/index.html`），不打开联网开关时没有任何网络请求，断网、飞行模式都能用。
- 网页是 `file://` 加载的，浏览器安全策略不允许它直接请求百度接口（接口不返回 CORS 头），所以联网翻译由**原生层代发**：网页调 `AndroidHost.translate(...)` → `NetTask` 在后台线程拼签名请求 → `NetReply` 把结果回灌给 `window.__netDone(...)`。密钥只存在手机本地，不打进 APK。
- 联网只影响英文。中文标五笔、练习模式、资源包全部本地。
- 五笔码是 **86 版单字全码**（3 码字 3 码，4 码字 4 码），不处理词组和简码。
- 英汉词典来自 ECDICT 精简版，只取每个词第一个中文义项，所以是「逐词对译」而不是整句翻译。
- 为了让逐词对译能读，`resources\english\fix_en.js` 里有一张 **508 条的修正表**（功能词 + 高频短语），优先级高于词典：冠词 `the/a/an` 直接不输出，`over` 译作「越过」，`look forward to` / `get up` / `go to bed` 这类短语整段替换。语序和语法仍然按英文原序，所以复杂长句依旧会别扭——这是纯离线方案的天然上限。打开「联网翻译」后整句交给百度，流畅度就是正常机器翻译的水平。
- 「中文译英」是实验功能，靠反查词典 + 常见词优先表，适合看单词英文，不适合当句子翻译。
- 生僻字若五笔表里没有，字会正常显示但上方留空，不报错。
- 手机端输出区 / 文章区**限高并内部滚动**（34vh / 38vh），保证软键盘弹出时输入框始终露在屏幕里；矮屏（≤720px 高）会自动再压一档。
- 夜间模式、侧边栏、联网翻译只作用于手机版（`www\` 里的 `mobile.css` / `mobile.js`），电脑版 `..\pc\` 保持原样、没有侧边栏。电脑版受浏览器跨域限制做不了联网翻译。
- 目前只在雷电模拟器（Android 9）和桌面浏览器窄屏下验证过，未在真机出厂系统上测。

### 1.3 联网翻译对比（实测）

| 英文 | 离线（1.2） | 联网（1.3，开了开关） |

### 英文翻译改善前后对比

| 问题 | 1.1（修之前） | 1.2（现在） |
| --- | --- | --- |
| 冠词照译 | `the` → 那、`a` → 第一个字母 | 不输出（中文不需要冠词） |
| 高频词选错义项 | `over` → 结束、`will` → 意志、`can` → 装罐 | 越过 / 将 / 能 |
| 最常用动词词典里没有 | `is / are / was / were / has / had` 显示橙色「没查到」 | 是 / 是 / 是 / 是 / 有 / 有 |
| 短语被拆开硬译 | `look forward to` → 一看 · 向前的 · 到 | 期待 |
| 整句效果 | `The quick brown fox jumps over the lazy dog.`<br>→ 那 快 的 褐色 狐狸 跳跃 **结束** 那 懒惰 的 狗 | → **快 的 褐色 狐狸 跳跃 越过 懒惰 的 狗** |
| 另一句 | `I look forward to your reply.`<br>→ 我 一看 向前的 到 你的 答复 | → **我 期待 你的 答复** |
