# 五笔打字提示器 · 电脑先行版

双击 **`index.html`** 就能用浏览器打开运行，**完全离线**，不装任何东西、不联网。

---

## 一、怎么用

### 日常模式（打开就是）

| 位置 | 内容 |
| --- | --- |
| 上半 | 输入框，随便打字 |
| 下半 | 输出框，**汉字上方标出该字的五笔字母**，字与字之间留了间距，方便对照 |

输入内容的处理规则：

- **汉字** → 原样输出，每个字上方给出五笔 86 全码（如 `我` 上方是 `TRNT`）
- **英文** → 自动查词典翻成中文，译文同样标五笔
- **其他语言 / 不明字符** → 原样输出，并在下方红条提示「无法理解」
- **混在一起** → 各按各的规则处理，互不影响

左下角的下拉框有三种输出方式：

- `自动检测`：默认，按上面的规则走
- `仅标注五笔`：英文不翻译，只给汉字标五笔
- `中文译英（实验）`：把中文词译成英文（离线词典反查，属于实验功能，长句语法不通顺）

### 练习模式（点右上角 `◎ 练习 learn`）

- **上半**：由常用 1000 字组成的十篇文章，可下拉换篇
- **下半**：输入框，照着上面的文章打
- 打完一个字，文章里对应的字**上方就出现它的五笔字母**，打对的字变绿
- 标点、空格不用打，自动跳过
- 进度条显示 `已打 / 总字数`，全打完会报用时和错字数
- 再点右上角（这时写着 `↩ 日常 返回`）回到日常模式，按钮文字跟着变

练习界面里的两个按钮：

| 按钮 | 作用 |
| --- | --- |
| `答案对照模式 开/关` | 开着时**全篇每个字上方都显示五笔**，可以先看答案；打错的字标红 |
| `逐字五笔提示 开/关` | 开着时打一个字才出这个字的五笔（默认开） |

快捷键：`Ctrl + Enter` 在两种模式间切换。

## 三、怎么更新资源包

所有资源包都是**普通 JS 文件**，用记事本就能改。改完保存，刷新浏览器即生效，不用重新打包。

每个资源包都是「一个注册函数 + 一个 data 字符串」，`data` 里用反引号包住纯文本：

### 1. 五笔表 `resources/wubi/wubi86.js`

```js
window.registerWubiPack({
  id: "wubi86", name: "五笔86 单字全码", version: "1.0",
  data: `
上 HHGG
的 RQYY
下 GHI
`
});
```

每行 `汉字` + 空格 + `五笔全码`（大小写都行）。想加字、改码，直接在这段里增删行。

### 2. 常用字 `resources/chinese/common1000.js`

```js
window.registerCommonChars({ id: "common1000", name: "常用1000字", data: `是了在一不有人和…` });
```

`data` 就是一串汉字，换行空格都会被忽略，写多少个字都行（改多了也不影响文章校验，只是练习时的字数统计仍按文章算）。

### 3. 英汉词典 `resources/english/ecdict_en2cn.js`

```js
window.registerEnglishPack({ id: "ecdict-en2cn", …, data: `the<TAB>那
be<TAB>是,表示,在` });
```

每行 `英文` + **Tab 制表符** + `中文释义`。多个义项用英文逗号分隔，程序只取第一个义项。

> 记事本里打 Tab：按一下 `Tab` 键即可。若不方便打 Tab，用**两个以上空格**隔开也行，解析器两种都认。

### 4. 汉英词典 `resources/english/ecdict_cn2en.js`

```js
window.registerChineseEnPack({ id: "ecdict-cn2en", …, data: `是<TAB>be,yes,yeah
学习<TAB>study,learn` });
```

每行 `中文词` + Tab + `英文候选`（逗号分隔，取第一个）。程序做最长匹配，所以「天安门」会优先于「天」被命中。

### 5. 英译修正表 `resources/english/fix_en.js` ★最常改的一个

离线词典只给了「单词的第一个义项」，所以 `the` 会译成「那」、`over` 会译成「结束」。这张表用来把这些常见错误盖掉，优先级**高于**词典：

```js
window.registerEnglishFix({ id: "fix-en", …, data: `
the =
over = 越过
look forward to = 期待
` });
```

- 每行 `英文 = 中文`
- **右边留空**表示这个词不输出（冠词 a / an / the 就是这样处理的）
- 多词短语用空格分隔，程序会先试最长的短语（最多 4 个词），命中就整段替换
- 词形会自动还原：`looking` / `jumps` / `studies` 都能匹配到 `look` / `jump` / `study`
- 发现哪句译得别扭，就在这里加一行，刷新页面立刻生效

### 6. 文章 `resources/articles/articles.js`

```js
window.registerArticles({
  id: "articles-10", name: "常用千字十篇", version: "1.0",
  data: [
    { title: "一天", text: "早上六点，我起来。……" },
    { title: "我的家", text: "……" }
  ]
});
```

- 想加文章：在 `data: [` 后面按同样格式加一条 `{ title: "...", text: "..." }`，注意**逗号分隔**
- 想换文章：直接改 `text`
- 用字建议仍在常用 1000 字内、且每个字五笔表里有码，这样练习才顺手
- 文章数量不限于 10 篇，下拉框会自动列出来

## 四、自检

想确认资源包都正常加载，打开这个地址（也可以直接在地址栏改）：

```
index.html?selftest=1
```

页面顶部会打印一份自检报告，正常情况下是：

```
==== 自检结果：45 通过 / 0 失败 ====
资源包：五笔 20910 字 / 英汉 41969 词 / 汉英 46898 词 / 常用 1000 字 / 文章 10 篇
```

如果某个资源包被改坏了，这里会变成 `FAIL`，并指出是哪一项。

其它可用的地址参数（主要给调试 / 演示用）：

| 参数 | 作用 |
| --- | --- |
| `?text=你好hello` | 预填日常模式的输入框 |
| `?out=zh2en` | 预先把输出方式设成「中文译英」 |
| `?mode=learn` | 直接进练习模式 |
| `?mode=learn&typed=早上六点` | 进练习模式并预填已打的字 |
| `?mode=learn&compare=1` | 进练习模式并打开答案对照 |

## 五、说明与已知限制

- 五笔码用的是 **86 版单字全码**（3 码字就 3 码，4 码字 4 码），不处理词组和简码。
- 英汉词典来自 ECDICT 精简版，只取每个词的第一个中文义项，所以是「逐词对译」而非整句翻译。
- 「中文译英」是实验功能：靠反查词典做最长匹配 + 常见词优先表，适合看单个词的英文，**不适合当句子翻译用**。
- 生僻字若五笔表里没有，字会显示但上方留空，不会报错。
- 界面按电脑浏览器做的，窄屏（手机）也能看，但不是主要目标。
- 手机版（`..\phone\`）多了侧边栏、夜间模式、联网翻译；电脑版没有。`app.js` 里留了联网替换的接入点（`window.__netHook`），但浏览器打开本地文件时受跨域限制拿不到百度接口，所以电脑版不启用。
